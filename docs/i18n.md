# Interface languages

The language switcher offers English (`en`), Filipino (`fil`), and Bisaya
(Cebuano, `ceb`). It translates interface labels such as navigation, page
headings, and action buttons; city records remain in English so translation does
not alter official-source claims.

Part 2 navigation, page names, filters, table headings, status labels, and
empty-state text use keys in all three locale JSON files. The locale catalogs
are checked to ensure every English key has a Filipino and Bisaya entry.

The selected language is stored in `localStorage` when available. If storage is
blocked, the current selection still works for the page session. Missing
translation keys fall back to English.

**Filipino (`fil.json`) and Bisaya (`ceb.json`) need native-speaker review.**
Do not present these draft strings as an approved translation.
